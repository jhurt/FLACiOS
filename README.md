# FLACiOS
Xcode project to create a libFLAC XCFramework for use in iOS apps.

## Note
As of iOS 11 FLAC is supported natively in Core Audio

## Build XCFramework
```sh
./build_xcframework.zsh
```

## Usage
- Drag and drop `FLACiOS.xcframework` to your project.
